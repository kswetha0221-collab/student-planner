# Student Planner

A beginner-friendly student planner built with HTML, CSS, and JavaScript.

## Features
- Add tasks with a subject and due date
- Mark tasks as completed
- Filter all, pending, and completed tasks
- Delete tasks
- View total, completed, and pending task counts
- Save tasks in browser local storage

## How to run
1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Add your tasks and start planning!

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser Local Storage
